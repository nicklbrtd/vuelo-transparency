# Известные ограничения

[English](../en/known-limitations.md) · Русский

Последняя проверка: 2026-09-28<br>
Статус: Актуально

Здесь описаны важные для пользователя ограничения, а не инструкции по эксплуатации уязвимостей.

| Ограничение | Область | Статус | Влияние на конфиденциальность |
|---|---|---|---|
| Групповые и канальные переписки не покрыты текущим E2EE-транспортом один на один. | Сообщения | Текущее ограничение; E2EE групп запланировано. | Их текущий серверный путь не имеет той же гарантии содержимого. |
| Старая история переписки один на один может оставаться на сервере в открытом виде. | История сообщений | Текущее ограничение | Новая защита не шифрует старую историю задним числом. |
| Шифрование вложений покрывает только часть сценариев: подключён текущий путь голосовых сообщений один на один, но полное покрытие медиа не установлено. | Медиа | Частично / в проверке | Нельзя считать каждый загружаемый объект шифротекстом. |
| Не подтверждено покрытие SQLCipher всех локальных данных. | Локальное хранение | Частично | Другие кэши, настройки, старые данные и открытые медиафайлы могут иметь другую защиту. |
| Пользовательская проверка ключа контакта и прозрачность ключей не подтверждены. | Идентичность | Не установлено | Нельзя считать, что пользователь независимо сверил ключ собеседника. |
| Полные гарантии E2EE для нескольких устройств и отзыва устройств не установлены. | Устройства | Частично / в проверке | Нельзя предполагать, что закрыты все сценарии жизненного цикла устройств. |
| E2EE-резервные копии и восстановление не найдены. | Резервные копии | Запланировано | Гарантии конфиденциальности при восстановлении и синхронизации не обещаются. |
| Production-миграции/настройки и полное поведение E2EE в runtime не проверялись. | Развёртывание | В проверке | Связанный в коде путь не доказывает идентичную конфигурацию живой среды. |
| Независимого аудита безопасности третьей стороной не было. | Проверка | Ещё не проводился | Внешняя гарантия аудита не заявляется. |
| Удалённая доставка push и содержимое уведомлений не подтверждены. | Уведомления | Не установлено | Гарантии приватности payload уведомления не заявляются. |

Ограничения обновляются, когда меняются соответствующие пользовательские сценарии или серверные контракты.
