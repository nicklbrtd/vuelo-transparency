# Статус исходного кода

[English](../en/source-status.md) · Русский

Последняя проверка: 2026-09-28<br>
Статус: Актуально

Vuelo пока не является open source. Исходный код приложения и реализация backend остаются приватными. В этом репозитории публикуется только документация о безопасности, приватности и прозрачности.

Публичная документация не делает приложение open source. Описание публичных протоколов и библиотек не означает публикацию исходников Vuelo. Этот репозиторий не выдаёт лицензию на использование, изменение или распространение кода приложения, названия продукта или бренда Vuelo.

В будущем Vuelo может отдельно опубликовать некоторые компоненты с явной лицензией. Обязательства или сроков публикации всего приложения нет.
