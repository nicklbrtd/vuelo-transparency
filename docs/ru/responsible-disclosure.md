# Сообщить об уязвимости

[English](../en/responsible-disclosure.md) · Русский

Последняя проверка: 2026-09-28<br>
Статус: Актуально

Пожалуйста, не публикуйте подробности уязвимостей, код эксплуатации, персональные данные или сведения об аккаунте другого пользователя в публичном issue.

Используйте функцию GitHub **Report a vulnerability** / приватную передачу сообщений об уязвимостях, когда она включена для этого репозитория. Если такой возможности нет, не публикуйте подробности публично; попросите владельца репозитория через приватный канал GitHub настроить конфиденциальный способ связи. Сейчас у Vuelo нет отдельного публичного адреса электронной почты для сообщений безопасности.

Полезное сообщение может содержать версию или номер сборки, краткое описание, влияние и шаги воспроизведения на аккаунтах и данных, которыми вы управляете. Не получайте доступ к чужим данным и не изменяйте и не сохраняйте их. Дайте время на первичный разбор и исправление до публичного раскрытия.

Политика относится к проблемам безопасности клиента Vuelo и публичной документации. Она не разрешает тестирование против других пользователей или за пределами обычного использования сервиса.
