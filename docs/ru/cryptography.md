# Криптография

[English](../en/cryptography.md) · Русский

Последняя проверка: 2026-09-28<br>
Статус: Актуально

Список ограничен примитивами и библиотеками, подтверждёнными в текущем коде. Он описывает использование, но не независимую проверку.

| Примитив или поставщик | Назначение | Текущий статус |
|---|---|---|
| Signal Protocol через LibSignalClient | Создание сессий и шифрование/расшифровка сообщений один на один через официальные связки. | В проверке · Независимый аудит не проводился. |
| Подписанные и одноразовые Signal prekey | Публичные prekey-наборы для текущего E2EE-транспорта. | В проверке. |
| Kyber prekey через LibSignalClient | Включён в текущую настройку prekey. Этот репозиторий не утверждает независимо подтверждённую post-quantum гарантию. | В проверке. |
| AES-GCM через Apple CryptoKit | Хранилище «Сохранённых сообщений» и блочное шифрование вложений. | Частично · Независимый аудит не проводился. |
| SHA-256 через Apple CryptoKit | Контрольная сумма шифротекста для проверки целостности вложения. | Частично. |
| P-256 через Apple CryptoKit / Secure Enclave | Отдельные ключи подписи и согласования устройства, если функция доступна. | Частично. |
| Apple Keychain и Security framework | Локальное хранение отдельных сессий и ключей; безопасные случайные байты для ключа «Сохранённых сообщений». | Реализовано для указанных сценариев. |
| Swift SystemRandomNumberGenerator | Байты префикса nonce для формата вложений. | Используется в пути вложений; независимой проверки не было. |

Vuelo не реализует примитивы Signal Protocol самостоятельно. Приложение реализует собственную интеграцию приложения, транспорта и хранения, а также отдельные форматы аутентифицированного шифрования для вложений и «Сохранённых сообщений». Независимой проверки этих форматов не проводилось.
