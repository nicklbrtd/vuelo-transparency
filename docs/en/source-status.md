# Source code status

English · [Русский](../ru/source-status.md)

Status: Current

Vuelo is not currently open source. The application source code and backend implementation remain private. This repository publishes public security, privacy, and transparency documentation only.

Public documentation does not make the application open source. Describing public protocols or libraries does not publish Vuelo's source code. This repository does not grant a license to use, modify, or redistribute Vuelo's application source, product name, or branding.

Vuelo may publish selected components separately in the future, each with an explicit license. There is no commitment or schedule to open the full application.
