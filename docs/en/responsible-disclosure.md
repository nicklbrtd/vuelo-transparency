# Report a security issue

English · [Русский](../ru/responsible-disclosure.md)

Last reviewed: 2026-09-28<br>
Status: Current

Please do not post vulnerability details, exploit code, personal data, or information about another user's account in a public issue.

Use GitHub's **Report a vulnerability** / private vulnerability reporting feature for this repository when it is enabled. If that option is not available, do not publish the details publicly; ask the repository owner through a private GitHub channel to enable a confidential reporting route. Vuelo does not publish a dedicated security email address at this time.

A useful report can include the affected app version or build, a concise description, impact, and steps to reproduce using accounts and data you control. Do not access, modify, or retain another person's data. Please allow time for triage and remediation before public disclosure.

This policy covers security issues in Vuelo's client and public security documentation. It does not authorize testing against other users or infrastructure beyond ordinary use of the service.
