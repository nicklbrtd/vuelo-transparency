# Security reporting

English · [Русский](docs/ru/responsible-disclosure.md)

Please do not report vulnerabilities through public issues or include exploit details, personal data, or another user's account information in a public post.

When enabled, use GitHub's private **Report a vulnerability** feature for this repository. If it is unavailable, do not disclose details publicly; contact the repository owner privately on GitHub and request a confidential reporting route. Vuelo does not currently publish a dedicated security email address.

Include the affected app version/build, a concise description, impact, and reproduction steps using accounts and data you control. Do not access or alter other users' data. Please allow time for triage and remediation before public disclosure.

See the [full reporting policy](docs/en/responsible-disclosure.md).
