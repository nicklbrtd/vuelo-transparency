# Source code status

English · [Русский](docs/ru/source-status.md)

Vuelo itself is currently closed-source. The application source code and backend implementation remain private. This repository publishes security, privacy, and transparency documentation only.

Documentation does not make the application open source. Descriptions of public protocols or dependencies are not Vuelo source code. No license to use, modify, or redistribute the app source, product name, or branding is granted here.

Vuelo may publish selected components separately with explicit licenses in the future. There is no commitment or schedule to open the full application.
